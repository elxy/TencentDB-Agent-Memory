# ernest trim

This branch is [TencentDB-Agent-Memory](https://github.com/TencentCloud/TencentDB-Agent-Memory)
tag **v2.0.2** (`99a1a2c251741658917e3fa700bf8e337ad15a5f`) plus the Ernest trim.
Ernest spawns a local MemoryCore process and talks to it over the `/v3` data plane
only (see `ernest`'s `runtime/memory-core-server.mjs`), so everything the gateway
needs to run as a hosted service is removed here.

`manifest.json` is the authoritative record of the trim. It was generated by a
blob-level comparison of the trimmed tree against `v2.0.2`, so replaying it onto
the same base commit is deterministic:

| kind | count | meaning |
|---|---|---|
| modified | 31 | L1 content history, L3 three-document API, isolation scopes |
| added | 18 | `src/core/content/*`, `src/gateway/content-write-handlers.ts`, ... |
| removed | 99 | plugins (openclaw/pi/hermes), scripts, docker, persona, docs |

## Replaying the trim onto another checkout

```bash
git checkout -b ernest 99a1a2c          # the manifest refuses any other base
trim/replay.sh <trimmed-snapshot-dir>   # snapshot = a tree with src/ at its root
```

`replay.sh` copies the 49 changed/added files, `git rm`s the 99 removed ones and
prints the counts. It does not commit.

## What Ernest depends on here

- `/v3/content/write` with `layer=l1` `change=create|retire` and `layer=l3`
  `create|revise` (`src/gateway/content-write-handlers.ts`) — **local addition**;
  upstream has no such handler at any ref.
- Content history (`src/core/content/*`, `src/core/store/sqlite/content-history.ts`)
  and the profile scope (`src/core/profile/profile-scope.ts`).
- `runtime/memory-core-server.mjs` imports the TS sources through this tree's
  `node_modules/tsx`; install with `npm ci` **inside `MemoryCore/`** after cloning.

## Tests

Upstream ships no unit tests for `MemoryCore/` at v2.0.2 (`package.json` says
`vitest run`, but there are no `*.test.ts`). The acceptance suites Ernest relies
on are the node:test files in `tests/`, which drive the real `handleV2Route`
dispatcher, the real SQLite store with content history enabled, and the real
local history planner over a temp directory:

```bash
npx --prefix MemoryCore tsx tests/http.test.mjs
npx --prefix MemoryCore tsx tests/trim-generation.test.mjs
npx --prefix MemoryCore tsx tests/trim-http-write.test.mjs
```

They expect `tests/` to be a **sibling** of `MemoryCore/` (the imports are
`../MemoryCore/src/...`).

## Upgrading upstream

```bash
git merge v2.0.3        # only 31 files carry local changes; conflicts stay local
npm ci --prefix MemoryCore
npx --prefix MemoryCore tsx tests/http.test.mjs    # the guards must still hold
```
